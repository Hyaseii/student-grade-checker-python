# Student Grade Checker

A simple Python program for checking student grades and their status.

## Features

- Check a student's grade
- Show all student grades
- Determine whether a student passes or fails
- Handle students that are not found
- Simple menu-based interface

## Concepts Used

This project was created to practice basic Python concepts:

- Variables
- Input and output
- If / Else
- While loop
- For loop
- Dictionary
- Functions
- Function parameters
- Return values

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python student-grade-checker-python.py
